GPA CALCULATION SYSTEM

Development of a GPA Calculation System Using C Programming

1. Project Introduction

The GPA Calculation System is a simple C-based application designed to calculate a student's Grade Point Average (GPA) using marks obtained in different subjects.

2. Project Objectives

- To calculate the average marks of students.
- To calculate GPA automatically.
- To reduce manual calculation errors.
- To provide a simple and user-friendly system.

3. Subjects

The system includes the following eight subjects:

1. Advance Calculus
2. Introduction to Computing
3. Ordinary Differential Equation
4. Digital Logic Design
5. Computer Programming
6. Data Analysis
7. Computer Programming Lab
8. Language Lab

4. GPA Calculation Formula

Average Marks = Total Marks / Number of Subjects

GPA = Average Marks / 10

The GPA is calculated on a scale of 10.

5. Technologies Used

- Programming Language: C
- Compiler: Online GDB
- Version Control: GitHub

6. Features

- Student name and roll number input.
- Fixed list of eight subjects.
- Marks input from 0 to 100.
- Automatic average calculation.
- Final GPA displayed out of 10.

7. Future Scope

The project can be extended into a web-based GPA calculator with an interactive interface and automatic result generation.
